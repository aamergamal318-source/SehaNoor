# قادة الصحة | מנהיגי בריאות

موقع مبادرة «قادة الصحة في النقب» — المدرسة الشاملة أورط أبو ربيعة – كسيفة، ضمن برنامج أورط صحي.
אתר יוזמת «מנהיגי בריאות בנגב» — בית הספר המקיף אורט אבו רביעה, כסיפה, במסגרת אורט בריא.

**الموقع:** https://aamergamal318-source.github.io/SehaNoor/

موقع ثابت (HTML / CSS / JavaScript بدون أي أداة بناء) يعمل مباشرة على GitHub Pages.

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية: القصة، الحاجة، العادات، القيادة، الميدان، الأدلة، الأثر، الاستمرارية |
| `learn.html` | مركز المعرفة: المقالات، دليل الثانوي، التحديات اليومية، حاسبة BMI |
| `articles/*.html` | ثماني مقالات (المحتوى في `articles/article-data.js`) |
| `presentation.html` | عرض اللجنة (13 شريحة، ثلاثة أوضاع لغة) |
| `pledge.html` / `signatories.html` | الميثاق ولوحة الشرف (Google Sheets) |
| `assets/ort-bari-summary.html` | ملخص المشروع للطباعة |

## البنية

```
assets/
  css/  tokens.css (الألوان والخطوط والمسافات) · base.css (المكوّنات المشتركة) · ملف لكل صفحة
  js/   i18n.js (محرّك اللغتين) · site.js (السلوك المشترك) · ملف لكل صفحة
  img/  صور مُحسّنة (webp) · icons.svg (الأيقونات) · رموز QR
images/, logo/   الصور والشعارات الأصلية (أرشيف — لا تُحذف)
scripts/google-apps-script.gs   خادم الميثاق في Google Sheets
```

### الترجمة
العربية هي لغة المصدر داخل HTML، والعبرية بجانبها في السمات:
`data-he` (النص)، `data-he-html`، `data-he-aria-label`، `data-he-alt`، `data-he-placeholder`، `data-he-content`.
النصوص المولّدة في JavaScript تستخدم `SN.t({ ar: "…", he: "…" })`. أي نص جديد يجب أن يُضاف باللغتين.

### الأرقام
كل الأرقام المعروضة مأخوذة من شريحة «قياس الأثر» (1000 مشارك، 25 سفير صحة، 25 صفاً، 50%+ يحضرون الماء، 100+ زيارة). عند تحديثها، عدّلوها في: `index.html`، `presentation.html`، `assets/ort-bari-summary.html`.

### حاسبة BMI
للأعمار 5–19: المئين حسب العمر والجنس وفق جداول CDC 2000 (`assets/js/cdc-bmi-lms.js`). للبالغين: تصنيف منظمة الصحة العالمية. لا يُحفظ أي شيء ولا يُرسل.
